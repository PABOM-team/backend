# API 테스트

API 구현 또는 리뷰 시 사용한다.

1. 정상 흐름과 문서화된 모든 에러 상황을 Controller/통합 테스트로 검증한다.
2. 필수값 누락, 잘못된 값, 경계값, Enum, 소유권, 인증, HTTP 상태 코드를 테스트한다.
3. 해당되는 경우 트랜잭션 롤백, 동시 수정 충돌, 멱등 재시도, 페이지네이션을 테스트한다.
4. 삭제·복구 생명주기, 만료 경계, 연관 데이터 처리를 테스트한다.
5. 실제 JSON 계약과 Swagger OpenAPI 예시가 DTO와 일치하는지 검증한다.
6. 기존 테스트 픽스처와 프로젝트 관례를 따르고 운영 외부 서비스에 의존하지 않도록 테스트를 격리한다.
7. 가능하면 `./gradlew test --no-daemon`과 `./gradlew build --no-daemon`을 실행하고 실제 결과 및 환경 제약을 보고한다.

실행하지 않았거나 실패한 테스트를 성공했다고 보고하지 않는다.
