# 백엔드 코드 리뷰

API 관련 변경 사항을 병합하기 전에 사용한다.

점검 항목:
- 구현이 제공된 요청·응답 계약과 HTTP 상태 코드를 정확히 따르는가?
- Swagger의 정상·에러 응답 예시가 모두 정확하고 완전한가?
- 인증, 리소스 소유권, 데이터 노출 방지가 올바른가?
- 트랜잭션, 동시성, 멱등성, 예외 처리가 일관적인가?
- 마이그레이션이 안전하고 인덱스 및 기존 스키마와 호환되는가?
- 파일 참조와 삭제·보관 생명주기가 적절히 처리되는가?
- 정상·실패·보안·경계값·회귀 테스트가 충분한가?
- 요청 범위 밖 기능을 구현하지 않았는가?

문제는 심각도 순으로 정리하고 가능한 경우 파일 경로와 줄 번호를 제시한다. 확인된 버그와 질문·가정을 구분하고, 남은 위험과 테스트 상태로 마무리한다.
